# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

C# and Avalonia UI, sharing one codebase across Windows, macOS, and Linux.

## Users

People who regularly create and work with Markdown files and want a dedicated desktop app for reading, editing, organizing, and exporting them.

## Product purpose

Open, read, edit, organize, and export Markdown documents to PDF when needed.

## Operating context

Local desktop use. Users open individual `.md` files or folders containing multiple Markdown files, switch between documents, and reorder tabs.

## Capabilities and constraints

- Distributable desktop app for Windows, macOS, and Linux.
- Open Markdown files and folders; support multiple reorderable document tabs.
- Read and edit Markdown with a live rendered preview.
- Export PDFs locally.
- Collapse, restore, and resize the library, editor, and preview panels; persist layout preferences and offer light/dark themes.
- Associate `.md` files with the app. Windows provides a per-user **Open with** registration toggle; choosing the system default remains controlled by the operating system.
- UI languages: English and French, with system-language selection and English fallback.

## Product principles

- Keep documents local and easy to open.
- Make switching among many documents immediate.
- Preserve source text while making it comfortable to read.
- Keep editing and export in one desktop workflow.
- Support desktop operating systems from one codebase.
