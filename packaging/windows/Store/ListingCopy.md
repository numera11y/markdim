## Product name

markdim

## Short description

Edit Markdown with live preview, multi-document tabs, search and replace, and local PDF export. Free and open source.

## Description

markdim is a desktop Markdown workspace for Windows that brings your source, rendered preview, and document library together. Open a `.md` or `.markdown` file, work with a folder of documents, or start with a blank note. The preview updates as you write, and you can export a PDF directly from the app.

Write and review
Edit Markdown in the source pane and view the rendered result alongside it. The preview supports CommonMark and Markdig's advanced extensions, including tables, nested lists, task lists, links, and code blocks with syntax highlighting.

Organize your documents
Use reorderable tabs, the document library, search, and the heading outline to move through your notes. Find and replace text in the active document.

Make the workspace yours
Choose a light or dark theme, resize the library, editor, and preview panes, and adjust editor text size. Optional whitespace and line-ending markers help inspect source text.

Your documents stay on your device
markdim does not require an account and includes no cloud sync, ads, or telemetry. To display remote images referenced by a document, the app may request those images from their HTTPS hosts. The document itself is not uploaded.

markdim is free and open source under the MIT License. This beta is for x64 PCs running Windows 10 version 2004 (build 19041) or later, and Windows 11. The app interface is available in English and French.

## Product features

- Markdown source editor with live rendered preview
- Open `.md` and `.markdown` files or work with a folder
- Reorderable tabs, document library, and heading outline
- Search and replace in the active document
- Local PDF export
- Light and dark themes with adjustable workspace panes
- English and French interface
